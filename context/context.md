## Analisis de codigo fuente de un repositorio PHP en GitHub 

Se requiere realizar realizar una prueba para evaluar de que manera se puede desde GitHub realizar pruebas de codigo fuente para un proyecto en PHP, ya que CodeQL no cuenta de manera nativa este analisis, para esto se debe realizar:

- Crear un proyecto basico de login y registro de productos cuyo front esta hecho en html, css y javascript, el backend en PHP
- El codigo debe contar con vulnerabilidades, malas practicas, con el fin que cuando se realice el analisis hayan hallazgos
- Se debe generar una solucion simple para poder realizar el analisis de codigo fuente del proyecto, sin usar CodeQL, ni SonarQube para el analisis de codigo fuente y que se pueda visualizar el resultado del analisis preferiblemente en el mismo GitHub
